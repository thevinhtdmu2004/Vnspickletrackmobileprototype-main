# Database Volume Partition

Thư mục này được sử dụng làm phân vùng lưu trữ cho dữ liệu của PostgreSQL và cấu hình của pgAdmin chạy trên Docker.

## Cấu trúc thư mục
*   `postgres-data/`: Dữ liệu cơ sở dữ liệu PostgreSQL 17 (được mount tự động từ container).
*   `pgadmin-data/`: Dữ liệu cấu hình của pgAdmin 4.
