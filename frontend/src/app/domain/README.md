- User
- Member
- Coach
- Class
- Session
- AttendanceRecord
- Package
- RenewalRequest
- PaymentRenewal

Attendance MVP statuses remain exactly:

- Co mat
- Tre
- Hoc bu
- Vang
- Nghi phep
