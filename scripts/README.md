# Automation & Device Operations Scripts

Thư mục này dùng để lưu trữ các kịch bản tự động hóa (PowerShell, Bash, Python...) phục vụ cho việc vận hành, tích hợp thiết bị (như IoT gateways, đầu đọc thẻ, hoặc máy bắn bóng) và các tác vụ CI/CD tự động.

## Cấu trúc đề xuất
*   `devices/`: Kịch bản giao tiếp thiết bị ngoại vi.
*   `deploy/`: Kịch bản hỗ trợ CI/CD.
