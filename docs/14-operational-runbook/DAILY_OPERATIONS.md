# Daily Operations Runbook

## 1. Purpose

Defines daily operating routines for Admin and Coach.

---

## 2. Admin Daily Routine

```text
[ ] Open dashboard
[ ] Check today's classes
[ ] Check low-balance members
[ ] Check renewal requests
[ ] Confirm package renewals/payments if any
[ ] Review backup status
[ ] Export/backup if required
```

---

## 3. Coach Daily Routine

```text
[ ] Login as Coach
[ ] Open today's classes
[ ] Open session detail
[ ] Mark attendance
[ ] Review low/zero balance warning
[ ] Save attendance
[ ] Confirm attendance success
```

---

## 4. Member Routine

```text
[ ] Login as Member
[ ] Check remaining sessions
[ ] Check next class schedule
[ ] Review history if needed
[ ] Submit renewal request if low balance
```

---

## 5. End-of-day Checklist

```text
[ ] All sessions completed or cancelled
[ ] Attendance saved for all sessions
[ ] Package renewals recorded
[ ] Backup completed if required
[ ] Issues recorded
```
