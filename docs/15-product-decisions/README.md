# Product Decisions Documentation Index

## 1. Purpose

This folder stores product decision documents for VNS PickleTrack.

It complements the Decision Log and Architecture Decision Records by keeping product-level choices clear and traceable.

---

## 2. Documents

| File | Purpose |
|---|---|
| `PRODUCT_DECISION_LOG.md` | Product and scope decision log |
| `MVP_SCOPE_DECISIONS.md` | Decisions about MVP vs future scope |
| `ROLE_MODEL_DECISIONS.md` | Decisions about Admin / Coach / Member roles |
| `ATTENDANCE_RULE_DECISIONS.md` | Decisions about attendance statuses and deduction rules |
| `FUTURE_ROADMAP_DECISIONS.md` | Decisions and candidates for post-MVP roadmap |
| `DECISION_TEMPLATE.md` | Template for new product decisions |

---

## 3. Core Product Decisions Already Made

```text
- App supports 3 roles: Admin / Coach / Member.
- Coach must not see revenue.
- Member only sees personal data.
- Attendance has 5 MVP statuses.
- Học bù deducts one session.
- Member renewal is request-only.
- Admin confirms package renewal/payment.
- Prototype Freeze v1 should not expand without change control.
```
