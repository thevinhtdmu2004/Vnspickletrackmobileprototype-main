# MVP Scope Decisions

## 1. Purpose

Defines what is included in MVP and what should remain future scope.

---

## 2. MVP Included

```text
- Admin / Coach / Member login
- Role dashboards
- Member management
- Class/session management
- Attendance with 5 statuses
- Package renewal by Admin
- Renewal request by Member
- Reports with role restrictions
- Member self-service portal
- Backup/export baseline
```

---

## 3. Future Scope

```text
- Online payment
- Push notification
- Cloud sync
- Multi-club / multi-branch
- Advanced analytics
- Zalo integration
- Public app store release
```

---

## 4. Scope Control Rule

```text
After Prototype Freeze v1, new major modules require change request and product approval.
```

---

## 5. MVP Exit Criteria

```text
[ ] Admin flow complete
[ ] Coach flow complete
[ ] Member flow complete
[ ] Attendance/package balance stable
[ ] Role permission verified
[ ] UAT completed
[ ] Pilot readiness approved
```
