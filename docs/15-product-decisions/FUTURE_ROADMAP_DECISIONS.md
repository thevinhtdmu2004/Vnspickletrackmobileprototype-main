# Future Roadmap Decisions

## 1. Purpose

Tracks post-MVP roadmap candidates and product direction decisions.

---

## 2. Future Candidates

| Candidate | Status | Notes |
|---|---|---|
| Cloud sync | Candidate | Needed for multi-device/member own phone use |
| Push notification | Candidate | Useful for class reminders and renewal alerts |
| Online payment | Candidate | Requires payment provider and reconciliation |
| Zalo integration | Candidate | Useful in Vietnam context |
| Multi-club / multi-branch | Candidate | Needed for SaaS scale |
| Advanced analytics | Candidate | Revenue trend, retention, coach utilization |
| Audit log report | Candidate | Useful for Admin/security |

---

## 3. Not MVP

The following are not part of current MVP unless approved:

```text
- Payment gateway
- Cloud sync
- Multi-club tenant model
- Zalo Mini App
- Advanced analytics
- Public app store release
```

---

## 4. Roadmap Decision Rule

Before promoting a future candidate to active scope:

```text
[ ] Business value confirmed
[ ] User impact assessed
[ ] Technical complexity assessed
[ ] Security/privacy impact assessed
[ ] Backlog created
[ ] Product Owner approved
```
