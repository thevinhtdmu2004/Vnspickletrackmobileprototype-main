# Build & Release Process

## 1. Purpose

Defines the build and release process for future MVP implementation.

---

## 2. Release Types

| Type | Purpose |
|---|---|
| Prototype Freeze | UX/BA baseline |
| Internal Test Build | Developer/QA test |
| UAT Build | Stakeholder review |
| Pilot Build | Limited real use |
| Production Build | Live release |

---

## 3. Build Checklist

```text
[ ] Source branch confirmed
[ ] Version number updated
[ ] Build succeeds
[ ] Demo/test accounts reviewed
[ ] Environment config checked
[ ] Release notes prepared
[ ] Known issues documented
```

---

## 4. Pre-release Checklist

```text
[ ] Admin flow passed
[ ] Coach flow passed
[ ] Member flow passed
[ ] Coach cannot see revenue
[ ] Member only sees personal data
[ ] Attendance rules passed
[ ] Package renewal rules passed
[ ] Backup/export reviewed
```

---

## 5. Release Notes Format

```text
Version:
Date:
Build type:
Commit/branch:
Included changes:
Known issues:
Rollback notes:
Approval:
```

---

## 6. Approval

Suggested approval before Pilot/Production:

```text
[ ] Product Owner
[ ] PM/BA
[ ] Technical Lead
[ ] UAT Representative
```
