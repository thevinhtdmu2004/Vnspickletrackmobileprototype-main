# Pilot Deployment Plan

## 1. Purpose

Defines the plan for deploying VNS PickleTrack to a limited pilot environment.

---

## 2. Pilot Objective

Validate the MVP with real or semi-real operations before production release.

Focus areas:

```text
- Admin operation
- Coach attendance flow
- Member self-service
- Attendance/package balance correctness
- Backup/export discipline
- Usability in real class context
```

---

## 3. Pilot Scope

Recommended first pilot:

```text
- 1 club or training group
- 1 Admin
- 1–2 Coaches
- 10–30 Members
- 2–5 Classes
- 2–4 weeks of operation
```

---

## 4. Pilot Preparation Checklist

```text
[ ] Pilot owner assigned
[ ] Pilot users identified
[ ] Test/pilot data prepared
[ ] Admin trained
[ ] Coach trained
[ ] Member instructions prepared
[ ] Backup/export process explained
[ ] Support channel defined
[ ] Known issues shared
```

---

## 5. Pilot Success Criteria

```text
[ ] Admin can manage members/classes/packages
[ ] Coach can complete attendance during class
[ ] Member can view schedule/package/history
[ ] Attendance balance remains correct
[ ] Low/zero balance warnings are useful
[ ] Backup/export can be performed
[ ] No critical permission leakage
```

---

## 6. Feedback Collection

Feedback should be collected by role:

| Role | Feedback Focus |
|---|---|
| Admin | Management, reports, package renewal, backup |
| Coach | Speed, usability, attendance accuracy |
| Member | Clarity, schedule, package balance, renewal request |

---

## 7. Pilot Exit Decision

At the end of pilot, decide:

```text
- Ready for production
- Needs fixes before production
- Needs another pilot cycle
- Scope should be reduced or expanded
```
