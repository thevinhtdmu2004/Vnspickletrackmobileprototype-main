# Sprint Documentation Rules

## Required Reading Before Sprint Work

Before editing any file under `docs/08-sprints/` or implementing work for a sprint, Codex must read and follow:

```text
docs/07-codex-rules/rules/SPRINT_EXECUTION_RULES.md
docs/07-codex-rules/skills/SPRINT_WORKFLOW_SKILL.md
```

These sprint rules extend the repository root `AGENTS.md`. If there is any conflict, preserve the stricter rule and do not change product/business behavior silently.

---

## Scope

This instruction applies to:

```text
docs/08-sprints/
src/ changes made for sprint implementation
docs/ changes made to support sprint closure
```

---

## Operating Principle

```text
Read the sprint rule and sprint skill first.
Preserve the validated prototype flow.
Keep changes small, safe and traceable to sprint scope.
Never bypass role, revenue, attendance or package-renewal business rules.
```
