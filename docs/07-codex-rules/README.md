# Codex Rules & Skills Index

This folder contains operating rules, skills and prompts for ChatGPT Codex or AI coding agents working on VNS PickleTrack.

## Files

| File | Purpose |
|---|---|
| `CODEX_OPERATING_RULES.md` | General rules for Codex behavior in this repo |
| `CODEX_SKILLS.md` | Role-specific skills Codex should apply |
| `CODEX_TASK_PROMPTS.md` | Reusable prompts for common tasks |
| `CODEX_CHECKLISTS.md` | Review and validation checklists |
| `CODEX_DONT_TOUCH.md` | Areas and rules Codex must not change without approval |
| `SPRINT_AGENTS.md` | Required reading rule for sprint work |
| `rules/SPRINT_EXECUTION_RULES.md` | Sprint execution, validation and PR rules |
| `skills/SPRINT_WORKFLOW_SKILL.md` | Sprint workflow skill for continue/implement/review/close/PR tasks |
