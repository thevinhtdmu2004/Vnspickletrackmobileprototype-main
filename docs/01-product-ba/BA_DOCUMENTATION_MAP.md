This document maps the durable BA documentation stored in GitHub Issues.

## 3. Why Issues Are Used

GitHub Issues are used because Figma previously removed Markdown documentation from the repository during push.

Issues are durable and not overwritten by prototype source generation.

## 4. How to Use

- Product decisions: update BA Issues.
- Working summaries: update `/docs`.
- Visual documents: update Figma or `ScreenFlowDocument.tsx`.
- Development tasks: create new implementation issues.
