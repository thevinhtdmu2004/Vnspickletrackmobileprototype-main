# Roadmap — VNS PickleTrack

## Phase 0 — Prototype Discovery

Status: Completed

Outputs:

- 3-role prototype.
- Screen flow document.
- BA documentation issues.
- Demo-ready UI.

## Phase 1 — Prototype Review

Status: Next

Activities:

- Review with Admin stakeholder.
- Review with Coach user.
- Review with Member/Hội viên user.
- Capture feedback as GitHub Issues.
- Freeze MVP scope.

## Phase 2 — Production Planning

Activities:

- Decide production stack.
- Define data architecture.
- Create implementation backlog.
- Define release plan.
- Define pilot deployment model.

## Phase 3 — MVP Implementation

Activities:

- Build authentication.
- Build member/class/session management.
- Build attendance.
- Build package/renewal.
- Build role-based dashboards.
- Build reports.
- Build backup/export or backend sync.

## Phase 4 — Pilot Deployment

Activities:

- Deploy to one real Pickleball club/class.
- Collect operational feedback.
- Fix critical issues.
- Prepare v1 release.

## Phase 5 — Productization

Potential features:

- Cloud backend.
- Multi-club / multi-tenant model.
- Member mobile app.
- Notifications.
- Online payment.
- Coach performance reporting.
- Zalo Mini App or web portal.
