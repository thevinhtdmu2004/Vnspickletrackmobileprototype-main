# Prototype Freeze v1

## Status

```text
Prototype Freeze v1 — Admin / Coach / Member completed
```

## Freeze Scope

The current prototype includes:

- Admin journey.
- Coach journey.
- Member/Hội viên journey.
- Role-based dashboards.
- Attendance flow with 5 statuses.
- Package renewal and renewal request.
- Reporting screens.
- Backup/export screens.
- Access denied screen.
- Screen flow visual documentation.

## Freeze Rule

No new major module should be added without a change request.

Allowed changes after freeze:

- Wording corrections.
- Permission polish.
- UI consistency fixes.
- Bug fixes.
- Documentation updates.

Not allowed without approval:

- New major modules.
- New role.
- Major navigation redesign.
- Business rule change.
