# Data Privacy

## 1. Purpose

Defines privacy expectations for member/student data in VNS PickleTrack.

---

## 2. Personal Data

Member data may include:

```text
- Full name
- Phone number
- Level
- Class membership
- Attendance history
- Package balance
- Payment/renewal history
```

This data must be protected.

---

## 3. Privacy Rules

```text
- Member can only view own data.
- Coach can only view data needed for assigned classes/sessions.
- Admin can view full business data.
- Export CSV must be Admin-only.
- Backup files must be handled as sensitive data.
```

---

## 4. Data Minimization

Member screens should show only what the member needs:

```text
- Own schedule
- Own package
- Own attendance history
- Own payment history
- Own profile
```

Avoid showing:

```text
- Other member list
- Other member phone numbers
- Full class roster unless approved
- Revenue or business reports
```

---

## 5. UAT Privacy Checklist

```text
[ ] Member cannot access all-member list
[ ] Member cannot access another profile
[ ] Member cannot access revenue
[ ] Coach cannot access revenue
[ ] Export/backup is Admin-only
```
